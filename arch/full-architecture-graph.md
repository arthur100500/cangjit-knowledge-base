# Full architecture graph

The Architecture view displays all documented classes and their relationships by default, fitted to the viewport. Relationship filters hide only edges, not classes. Selecting a class highlights it without hiding other nodes or changing the user's pan and zoom; class details remain available separately.

The former focused-neighborhood view obscured the overall architecture. The full graph favors overview and relies on pan, zoom, filtering and class selection when a fitted graph is too dense to read, particularly on phones.
