# How CompileFunction constructs the frame and publishes metadata

`src/JIT/X86_64/Compilers/Function/CompileFunction.cpp` numbers values, builds an interference graph and allocates stack slots before emitting the function. The prologue reserves a four-byte metadata prefix, saves RBP, sets RBP to RSP and calls the immediately following marker. Its return address at RBP-8 is exactly entry+9, used by runtime frame discovery; the remaining frame is allocated with `StackFrameUtils::GetFrameSize(slots + 1)`. That extra slot accounts for the marker.

Parameter emission copies ABI register, SIMD or incoming stack arguments into their allocated stack locations, normalizing integer widths. Hidden generic, outer and this TypeInfo arguments are separately copied into context-managed frame slots for later type operations. The entry block is then compiled and an epilogue returns the value in the appropriate ABI register.

After emitting code, `CompileToAddress` records the computed frame size and marks all five tracked callee-saved registers unsaved (`UINT32_MAX`). It builds metadata once at provisional addresses to determine its size, aligns the code buffer to four bytes and embeds it. AsmJit allocates/publishes the combined buffer. It rebuilds metadata with actual addresses, writes descriptor and prefix through the allocator's writable span, registers lazy call sites, and returns allocation base + 4 as the executable entry. On errors after allocation it releases that allocation. Code and descriptor share allocation/lifetime and the relative prefix remains representable. See `jit-metadata-layout.md` for the descriptor.
